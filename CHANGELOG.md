# Changelog

All notable changes. Dates are 2026 unless noted.

## 2026-09-25

### Changed
- Review mode v2: evidence pack (renders at every width, load-sequence
  strip, calibration set), eyes-first two-pass critic, severity-based
  plateau rule, effective target 8.5 under a same-tier critic
- Define: concept ceiling gate + sameness test, device budget (≤5),
  regression invariants, LEAP/FIX rhythm with the bold-move menu,
  evidence harness for SPAs, findings verification before execution
- Model split: session model is the default reviewer; README recommends
  a stronger design model for the role

### Added
- `references/techniques.md` — the full technique map (scroll narrative,
  motion, layout, styles, 3D/immersive, APIs, combos)
- `tools/preflight.mjs` — generic floor + interaction-state matrix over
  CDP
- `wcd.mjs` — one-line CLI (init / render / preflight)
- LICENSE (MIT), CONTRIBUTING.md, CI

### Removed
- Demo artifacts from an early failed run (they no longer represent the
  protocol)
