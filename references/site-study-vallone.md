# Site study — vallone.de（VALLONE® 浴室设计）

学习对象：https://www.vallone.de （2026-09 抓取分析）
证据：`.vallone/`（首页与 /atelier 的整页截图与切片，不入库）

## 一句话

把"画廊逻辑"搬到电商：界面本身近乎无色无声，所有颜色、质感、情绪都由摄影与材料承担；排版用两种声部（几何无衬线管导航、高反差衬线管叙事）；动效慢到近乎静止，慢本身就是奢侈品信号。

## 可复用的设计决策（附证据）

1. **颜色来自内容，不来自界面**。critical.css 里 #000×166、#fff×129、#c7c7c7×73（发丝线/分隔线专用灰）、#f6f6f5 底——界面是 achromatic 的；青铜、绿大理石、胡桃木的颜色全部来自摄影。对照我们的评分标准：这不是"几种颜色"的问题，而是"颜色是否是一个决定"的最佳样本。
2. **双声部排版**。自托管 Radikal（几何 grotesque）以小号字距全大写管一切导航与标签；品牌宣言却用大号高反差衬线排成正文，且把 "VALLONE® ATELIER" 的无衬线字标直接嵌进衬线段落里——两种声部在同一行内对话。字号阶 1rem–5.4rem，但 76 处 1.3rem：绝大多数文字很小，页面在"耳语"，尺寸层级极陡（5.4rem 只留给 display）。
3. **无边框商品卡**。商品卡 = 图片 + 小号大写名 + 右端对齐的价格，三者一条基线，没有任何容器/按钮/边框——印刷目录的表格排版传统。名字左、价格右的分隔靠空白完成。
4. **留白即奢侈信号**。错列不对称的产品网格（一张大图 + 隔很远的一张小图）、整屏的空、半页图半页空。空洞是有意的，不是没排满。
5. **慢动效**。过渡长至 2s（cubic-bezier(0,0.5,0.5,1)），常规交互 cubic-bezier(0.25,1,0.5,1)（quart-out）；页面加载本身就是一条带 --time 变量的进度条动画。没有弹跳、没有视差轰炸——慢与稳就是高级。
6. **导航即内容**。菜单项（badmöbel / badewannen / waschbecken / armaturen，小写）直接叠压在 hero 摄影上，是画面的一部分而非浏览器 chrome。"ALLE PRODUKTE ANSEHEN →" 这类 micro-CTA 全站统一为小号大写+字距。
7. **工程服务于体验**。critical.css 内联、images.vallone.de CDN 按 `?w=&q=&fm=webp&fit=` 出响应式 webp、lazy loading、自托管字体。快，是奢侈品的一部分。
8. **文案声部**。"Beyond everyday. Beyond expected." 短陈述句、宣言式品牌叙事以 display 尺寸当正文排——文字本身是版式主角。

## 弱点（同样值得学）

- Cookie 弹窗是纯实用件，与整体的精致割裂（首屏第一眼被它定义）。
- 首屏只有氛围影像、无标题——品牌优先，转化与可理解性让位；慢网下懒加载会让首屏空白。
- 长宣言衬线正文在 40px 下漂亮但阅读效率低；检索/比价能力被氛围完全压制。

## 对本 skill 的映射

- 评分标准"颜色是决定不是默认"的正样本：vallone 的界面零装饰色，但摄影引入了多色相——按"元素禁令"的旧标准会误判，按"纪律与意图"的新标准是满分。
- "双声部排版"可加入野心 brief 的武器库：grotesque 管界面、衬线管叙事、字标嵌进句子。
- 无边框商品卡 + 基线对齐价格 = 印刷目录语法，适合任何产品页 brief。
