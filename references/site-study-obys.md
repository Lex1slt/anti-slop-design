# Site study — obys.agency（Obys Agency 设计工作室）

一句话：乌克兰设计工作室的排版实验场——标题与正文用自研衬线 "Obys" 以 canvas 绘制，做 kinetic typography；SSR HTML 里几乎抓不到文字，因为字是画出来的。

## 可复用决策

1. **自研字体当护城河**：连工作室都以自托管自研字体（Obys serif, woff2）立品味——字体即身份，不与任何网站撞字。
2. **Canvas 排版实验**： kinetic typography、文字随滚动变形——排版从"被渲染的内容"升级为"被表演的内容"。
3. **作品优先的叙事顺序**：工作室站 = 作品墙 + 极少量字。

## 弱点（重要）

Canvas 绘制的文字：不可选中、不可搜索、爬虫全盲（本次 SSR HTML 无任何 heading/链接文本）；可访问性与 SEO 代价极高。学习其审美可以，照搬渲染策略仅限工作室/艺术站。

## 映射

自研/独占字体是最高级的"不撞款"手段（成本也最高）；canvas 排版仅限作品本身就是排版的场合。
