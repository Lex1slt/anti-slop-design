# Site study — chronoswiss.com/en（Chronoswiss 瑞士制表）

一句话：传统制表品牌的"工艺微距"策略——整页几乎全是巨型材质微距摄影/视频，文字退成衬线字标与字距全大写的导航。

## 可复用决策

1. **100vh 工艺微距视频开场**：首屏是一整段绿松石漆面表盘的微距影片，无标题无 CTA——工艺本身就是论证。
2. **衬线字标 + 字距大写导航**：左上 "Chronoswiss / MODERN MECHANICAL" 双行衬线字标，导航 Questrial 无衬线大写加字距——仪表化的克制。
3. **Token 纪律**：Tailwind 全 token 化（--text-xs…--text-4xl、--font-serif/sans/mono），经典品牌也用设计令牌管理一致性；正文字体 EB Garamond（衬线叙事）。
4. **产品即 hero**：表款列表页不排卡片网格，而是一张占满全屏的产品微距（Delphis 绿松石跳时盘，No.34/99 限量编号入镜）——限量编号本身成了版式元素。
5. **单色 UI + 单一动作色**：界面全是中性灰（#e0e0e0/#f9f8f6），唯一的绿 #4dc247 属于 WhatsApp 联系按钮——颜色只给行动。

## 弱点

Cookie 横幅实用件割裂；100vh 视频让深层内容可发现性差；信息密度极低，比价/检索被氛围压制。

## 映射

"工艺微距作 hero"与"衬线字标+字距大写"适用于任何以工艺/材质为核心的产品；限量编号入镜是叙事细节的免费加分项。
