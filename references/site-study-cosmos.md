# Site study — cosmos.so（Cosmos 灵感收藏工具）

一句话：AI 灵感收藏工具，把"搜索/保存"这类工具动词浪漫化——"Every search opens a new world." / "Search the way you think." / "Know what you're looking at."；暗场开场 + 精致到极致的深色产品 UI。

## 可复用决策

1. **工具动词浪漫化**：把功能写成世界观——搜索不是检索，是"打开一个新世界"；AI 视觉标签写成 "Know what you're looking at."（一句话讲清 AI 能力，零术语）。工具类产品的文案范本。
2. **深色工具 UI 的完成度**：Next + React 的重交互产品，界面本身（网格、瀑布流、细节动效）就是卖点——工具页的"设计感"来自密度与秩序，不靠装饰。
3. **社会证明指向同行**："Inspiration for the world's top creative teams."——用户是谁，产品就是什么档次。
4. **渠道即气质**：Instagram / TikTok / Substack 并列入 footer——视觉工具的对外出口本身就是审美声明。

## 弱点

重 JS 渲染，无头/爬虫拿不到内容（本次截图暗帧）；342KB HTML 对首屏是真实成本。

## 映射

"工具动词浪漫化"三连句式（把功能写成世界观）可直接用于任何效率产品；深色工具 UI 的对标样本。
