# Site study — rhine.lubeiluchen.cc（RHINE LAB · ANALYSIS OS）

一句话：中国的独立佳作——网站伪装成一台正在启动的操作系统：暖纸色 boot 门（"INTERNAL DATABASE / READY"，终端风双线框"点击进入 →"），门后是三维研究档案终端。"ANALYSIS OS" 的命名即概念。

## 可复用决策

1. **OS/开机门隐喻**：整个站点是一台机器——boot 门显示状态文本（INTERNAL DATABASE / READY），按 Enter 开机；状态文本本身就是设计。
2. **终端风组件语法**：双线框按钮（外框 + 内框）、等宽字距的状态行、无限符号"＋−"logo——一套自洽的"仪器界面"词汇。
3. **档案色系**：暖纸 #e8e5e1 / 近黑绿 #080a08 / 青铜棕 #a67d48 / 灰卡其 #c1b8a7——档案馆的有色温配色，躲开蓝紫 AI 味。
4. **CJK 优先**：MiSans 承载中文，字距与行高按中文调——中文站的排版基准应该这样定。
5. **PWA 细节**：manifest + theme-color + apple-touch-icon 全套——"它是一台设备"的概念延伸到 meta 层。

## 弱点

点击/Enter 门是真实的进入摩擦；3D 终端内部无法被搜索引擎与截图看到；概念小众。

## 映射

"OS/boot 门 + 状态文本"适合任何档案、研究、数据类产品；暖纸+青铜的档案色系是蓝紫味的天然解药；双线框是零成本高辨识度的组件签名。
