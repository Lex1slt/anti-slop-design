# Site study — family.co（Family 加密钱包）

一句话：把一整个钱包官网做成"一屏一句收益宣言"的清单体——每屏只有一句大白话 H1 + 一段手工矢量动画，零照片、零术语、零按钮墙；暗场开场用手电筒光标揭示内容。

## 可复用决策

1. **一屏一句收益宣言**。全站 H1 依次是："Your favorite crypto wallet." / "Explore Ethereum in a whole new way." / "Send, receive, swap. All in one place." / "The best way to experience NFTs." / "Watch the wallets you care about." / "Wallet activity you can understand." / "Relentless protection. Restful ease." / "Effortless onboarding. Masterful management."——每屏一句、全是"主语+收益"、没有一个形容词。文案本身就是版式。
2. **零摄影，纯矢量场景**：每句配一段手工 Lottie/矢量动画（自研字体 LFE Sans + 自绘插画），没有一张 stock 图——加密行业常见的"3D 金属币+渐变"被完全绕开。
3. **信任写成事实**："audited by Zellic"（审计机构实名）、"Import from MetaMask / Phantom"（迁移成本一句话归零）。
4. **暗场 + 光标手电筒**：开场是暗色画布，光标是手电筒，扫到哪里揭示到哪里——交互即品牌。
5. **FAQ 也写成产品语气**："Is Family safe?" 而非 "Security information"。

## 弱点

全 JS 渲染 + 暗场揭示：爬虫、慢设备、截图什么都拿不到（本次无头截图全是暗帧）；每屏一句话的信息密度极低，效率型用户难受。

## 映射

"一屏一句收益宣言"是任何产品 landing 的黄金清单体——先写八句收益 H1，再为每句配一个场景；配合我们的评分标准：颜色/元素零争议，全部火力在语言与动效。
