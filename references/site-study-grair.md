# Site study — grair.undreamstudio.com（GRAIR 沉浸式珠宝体验）

一句话：Three.js 沉浸式珠宝体验——深紫夜幕、金属衬线字标的电影式 boot、Cormorant 衬线 + 三支无衬线的奢华字体层级。

## 可复用决策

1. **电影式 boot**：近黑紫背景、金属质感衬线 "GRAIR" 字标浮现、底部一条发丝进度线——进入正题前的 10 秒被做成预告片。
2. **字体层级**：display 用 Cormorant Garamond / Cormorant Infant（高反差奢华衬线），UI 层配 Inter / Manrope / Outfit 三支无衬线分工——一个页面四种字体但各司其职。
3. **产品即 3D 对象**：珠宝以 WebGL 物件呈现（可转、可近看），而非平面图——当产品本身就是立体作品时，3D 不是装饰是必需。
4. **深色不等于黑**：底色是带紫的 #0d0a12 系而非纯黑，配金属字标的冷高光——夜幕有色温。

## 弱点

全 JS 渲染：爬虫、截图、慢设备什么都拿不到（本次截图只有 boot 与暗场）；进入门槛与性能代价高；React + Three.js 全家桶成本大。

## 映射

"luxury = 高反差衬线 + 有色温的深色 + 发丝进度线"；3D 只在产品本身是立体作品时使用。
